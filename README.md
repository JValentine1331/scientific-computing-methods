# Scientific Computing Methods

A collection of numerical algorithms implemented from first principles while studying numerical analysis, scientific computing, and mathematical modeling.

The purpose of this repository is to develop a practical understanding of classical numerical methods through implementation, testing, and computational experiments.

## Topics

* Root Finding
* Linear Systems
* Interpolation and Polynomial Approximation
* Numerical Differentiation
* Numerical Integration
* Initial Value Problems for Ordinary Differential Equations
* Nonlinear Systems of Equations
* Eigenvalue Methods
* Approximation Theory
* Boundary Value Problems
* Partial Differential Equations

Each topic contains:

* `methods/` - algorithm implementations
* `notebooks/` - computational experiments and convergence studies
* `README.md` - topic overview and references

## Goals

* Implement numerical algorithms from first principles.
* Study convergence, stability, and error analysis.
* Compare numerical methods through computational experiments.
* Build a long-term reference library for scientific computing.
